# 🌐 My First HTML Website

Welcome to my first HTML website! 🎉

This is a simple beginner-level project created using **HTML (HyperText Markup Language)**. It displays a welcome message and a short paragraph.

## 📌 Project Preview

The webpage contains:

* A website title: **My Website**
* A main heading: **Welcome to My Website**
* A paragraph: **My HTML is working 🎉**

## 🛠️ Technologies Used

* HTML5

## 📂 Project Structure

```text
My-Website/
│
└── index.html
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

You can also use **Live Server** in VS Code.

## 🎯 Purpose

I created this project to practice the basics of HTML and learn how websites are structured.
